# HOTFIX V4.5.2 — Pulido visual adicional de landing

## Objetivo
Aplicar una segunda corrección enfocada en que la landing conecte mejor con el panel interno y con las plantillas de negocio, manteniendo el mismo patrón visual de WAMERCIO.

## Cambios aplicados

### 1) Preview adaptativo más claro
- Se agregó una vista interactiva dentro de la landing para seleccionar una plantilla activa.
- La landing ahora permite visualizar cómo cambia la experiencia según el tipo de negocio.

### 2) Conexión visual entre landing, plantilla y panel
- Se añadió un bloque de preview con sidebar estilo panel WAMERCIO.
- Ese preview muestra:
  - branding WAMERCIO consistente
  - módulos priorizados por plantilla
  - indicadores resumidos según el tipo de operación
  - bloques explicativos de qué funciones sí aparecen y por qué

### 3) Menor sensación de página estática
- La sección de plantillas dejó de ser solo informativa y ahora también demuestra comportamiento adaptativo.
- Se reforzó el mensaje de coherencia entre identidad visual, navegación y operación del comercio.

## Archivo principal tocado
- `apps/web/components/platform-landing.tsx`

## Resultado esperado
- Una landing más viva, más explicativa y más alineada con el producto real.
- Mejor continuidad visual entre página pública, plantillas y panel del negocio.
