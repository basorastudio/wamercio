# WAMERCIO 2.8.12

Release de mantenimiento sobre WAMERCIO 2.8.11.

Esta versión corrige la experiencia del mapa de ubicación de clientes: el mapa está embebido e interactivo dentro de WAMERCIO, permite zoom y desplazamiento, y la imagen de WhatsApp funciona como marcador geográfico real ligado a las coordenadas guardadas.

La experiencia pública conserva el flujo de catálogo, **Mi compra**, pedidos y cuenta del cliente.

Consulta `CHANGELOG.md` y `DEPLOY_DOKPLOY.md` para detalles de actualización.


## Bloqueo comercial por negocio (2.8.12)

Los negocios pueden bloquear a un cliente localmente indicando un motivo obligatorio. El bloqueo no afecta la cuenta global del cliente ni su acceso a otros negocios. Superadmin puede auditar los bloqueos por negocio.
