# Sistema visual WAMERCIO 1.4

Referencia visual: patrón de landing y UI tipo WhatsApp Food / WhatsMenu, adaptado a WAMERCIO con componentes y recursos propios.

## Paleta

| Uso | Color |
|---|---|
| Primario | `#36B385` |
| Primario oscuro | `#2B936D` |
| Primario suave | `#EEFAF6` |
| Texto principal | `#2E3154` |
| Texto secundario | `#8A8FA9` |
| Fondo | `#FAFBFE` |
| Superficie | `#FFFFFF` |

## Reglas de interfaz

- Verde para acciones primarias y navegación activa.
- Blanco y gris muy claro para superficies.
- Azul-violeta oscuro para títulos y texto principal.
- Tarjetas de radio pequeño/moderado; se evita el aspecto excesivamente redondeado.
- Sombras ligeras.
- Tipografía visualmente ligera: `font-medium`/`font-semibold` en lugar de pesos negros.
- CTA principal verde o blanco sobre fondos verdes.
- Estados de negocio conservan colores semánticos (error rojo, pendiente ámbar, etc.).

## Landing

1. Navbar sobre hero verde.
2. Hero en dos columnas con ilustración UI propia.
3. Corte diagonal inferior.
4. Grid de seis funcionalidades.
5. Bloque de proceso simple con mockup móvil.
6. Planes dinámicos sobre fondo verde.
7. Demo/QR sobre blanco.
8. Beneficios/casos de uso sobre verde.
9. Footer claro.

## Panel de tienda

- Sidebar blanco en escritorio.
- Elemento activo: fondo verde suave + indicador izquierdo.
- Bottom navigation móvil en blanco, activo verde.
- Tarjetas y tablas blancas sobre `#FAFBFE`.
- Modal y formularios con el mismo sistema visual.

## SuperAdmin

- Sidebar verde WAMERCIO.
- Navegación activa blanca.
- Área de trabajo gris muy claro.
- Login SuperAdmin verde + formulario blanco.

## Catálogo público
