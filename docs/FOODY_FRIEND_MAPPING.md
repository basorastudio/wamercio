# Foody Friend → WAMERCIO 1.1

Esta matriz documenta qué concepto funcional de Foody Friend se conserva y cómo se reinterpreta en WAMERCIO con código propio.

| Foody Friend | WAMERCIO |
|---|---|
| User Dashboard | Dashboard comercial |
| Stores | Tiendas |
| Store Schedule | Horarios en Ajustes de tienda |
| Store QR Code | QR público por tienda |
| Store Categories | Categorías |
| Store Menu / Products | Productos |
| Product Optionals | Extras del producto |
| Variants | Variantes del producto |
| Shipping | Zonas de delivery |
| Coupons | Cupones |
| Orders | Pedidos + estados |
| Payment status | Estado de pago manual separado |
| User Transactions | Movimientos |
| Purchase Plans | Plan y suscripción |
| Support Tickets | Centro de soporte |
| User Profile | Mi cuenta |
| Admin Users | SuperAdmin / Usuarios |
| Admin Stores | SuperAdmin / Tiendas SaaS |
| Admin Plans | SuperAdmin / Planes SaaS |
| Admin Purchase Plans | Solicitudes de plan |
| Admin Transactions | Movimientos SaaS |
| Admin Tickets | Tickets SuperAdmin |
| Bot de mensajería heredado | WAMERCIO multi-sesión por QR |
| Telegram / Messenger | No se incluyen |
| Gateway collection | Se elimina; solo pagos manuales configurables |

## Extensiones propias de WAMERCIO

Foody Friend se utilizó como referencia, pero WAMERCIO 1.1 añade:

- Centro de conversaciones real.
- CRM de clientes.
- Cliente bloqueado por tienda.
- Branding de tienda (banner/color).
- Checkout con validación completa en servidor.
- Control y restauración de inventario.
- Delivery o recogida según configuración.
- Métodos manuales configurables por tienda.
- SuperAdmin con aprobación de cambios de plan.
- Motor WhatsApp propio presentado al usuario como WAMERCIO.
